# Kyrene Dice

Welcome! Kyrene Dice is an open-source dice roller and probability calculator for dice pool–based roleplaying games such as _Vampire: The Masquerade_. For the long version, see [the About page](./public/docs/About.md) and other project documentation at [`./public/docs`](./public/docs).

(This is an unofficial and independent project. It is not affiliated with or endorsed by Paradox Interactive AB or any other publishers or owners of the games whose names or rules are mentioned.)

## Reporting Bugs

While this project is its current phase of development, in lieu of a full-featured issue tracker, I am using a simple ["known issues"](./public/docs/Issues.md) document to track the fixes, improvements, and features that I want to make.

You are welcome to contact [me](https://github.com/RyanSkonnord/) directly or [open an issue](https://github.com/RyanSkonnord/kyrene-dice/issues) if you find any bugs not already listed on the document.

## Contribution

This is currently a solo project, but feel free to reach out to [me](https://github.com/RyanSkonnord/) or open a [pull request](https://github.com/RyanSkonnord/kyrene-dice/pulls) if you are interested in collaborating.

## Usage

Build and run this project with [NPM](https://nodejs.org/en/download).

* `npm install` to download dependencies.
* `npm start` to host a local server for development or offline use.
* `npx tsc` to run TypeScript validation.
* `npm test` to run unit tests.
* `npm run build` to build the production-ready site.
